Architecture

clj-harness is a middleware-based agent harness for building AI-powered bots in Clojure. It connects LLM providers (OpenRouter, DeepSeek) with tools (MCPvisor, shell commands) through a composable pipeline of pure functions.

Pipeline

User Message
  ↓
create-bot (wires pipeline)
  ↓
handle-message (session, compaction, invoke pipeline)
  ↓
core-agent        ← raw LLM call, extracts assistant message
  → wrap-tools    ← automatic tool calling loop (calls LLM until text)
  → wrap-retry    ← exponential backoff on errors
  → wrap-logging  ← timing & finish reason telemetry
  ↓

Namespaces & Requires

compact.clj, core.clj

ns declares the file's namespace. :require imports other namespaces with aliases. Docstrings attach to the namespace as metadata — retrievable at runtime via (doc ...).

Functions as Values

middleware.clj

defn creates a Var holding a function. Functions are first-class: you pass them, return them, store them in maps. The middleware pattern is just (fn [handler] => fn).

(reduce f init coll) folds a collection into a single value. Used in estimate-tokens to accumulate token counts across messages. The function receives (accumulator, element) each iteration.

let — Immutable Bindings

all files

(let [x 1 y 2] ...) creates local bindings that never change. Not "variables" — they're names for values that exist only within that scope. No mutation, no reassignment.

Threading Macros

(-> val (f) (g) (h)) threads a value through functions — each result becomes the first argument of the next. Eliminates deeply nested calls. ->> threads as last argument.

Metadata (^:private)

(def ^:private x ...) attaches metadata to a Var. ^:private tells the compiler "don't let other namespaces access this." Not a lock — reachable via #'ns/var — but a clear boundary signal.

Data-Driven Dispatch

llm.clj:15

provider-config is a map, not a switch statement. Each provider = {:url :headers}. Adding a new provider means adding a map entry — no code changes needed. Data > Code.

(loop [x 0] ... (recur (inc x))) — the tool calling loop uses loop/recur for iterative recursion without stack overflow. JVM doesn't have TCO, so Clojure provides explicit recur.

Bugs Found & Fixed

Parameter Shadowing: name → tool-name

Location: tools/shell.clj
Symptom: ClassCastException: String cannot be cast to IFn
Root cause: The parameter name (tool name string, e.g., "echo") shadowed clojure.core/name inside the function body. When the schema construction called (name k), it tried to invoke the string as a function.

Fix: Renamed parameter to tool-name, unshadowing clojure.core/name.
Lesson: Never use name, key, val, get, count, type, or class as parameter names — they're all clojure.core functions that shadow silently.

Unused Namespace Import

Location: middleware.clj
Symptom: LSP warning — clojure.string required but never used
Root cause: Copied clojure.string from core.clj's ns during extraction. Middleware doesn't use any string functions.

Fix: Removed [clojure.string :as str] from requires.

Key Design Decisions

DecisionWhy
Middleware over monolith Each concern is a composable function. Test individually. Swap order easily. No circular deps.
Raw Java HttpClient (HTTP/1.1) MCPvisor rejects HTTP/2. Works for all providers. No extra dependencies.
Cheshire JSON, string keys (parse-string s false) = string keys, matching LLM JSON conventions. true = keyword keys for Clojure-native maps.
Atoms for sessions Thread-safe, REPL-inspectable. swap! is atomic — no locks needed for concurrent message additions.
Pure recursion agent loop No mutable state in the agent loop. loop/recur for iteration without stack overflow.
Aero config #env and #or for env-aware .edn on classpath. No YAML, no JSON config.
Data-driven provider dispatch Adding a provider = adding a map entry. No switch/case, no if-else chains. Data > Code.
Function injection for DI compact doesn't import core-agent — it receives summarize-fn as a parameter. Zero circular dependencies.
